# Example — React + ASP.NET Core Feature

User:
"Add refresh-token reconnect to the dashboard session."

1. Captain records original prompt.
2. Intent & Discovery creates a meaning-preserving Intent Contract.
3. Discovery inspects current auth/session frontend + backend code.
4. Architect maps the minimum affected components.
5. Backend/Frontend proposed work becomes registered steps.
6. Plan Validator removes unnecessary steps and approves required ones.
7. Backend implements its approved step.
8. Handoff Validator verifies actual endpoints/contracts before frontend consumes them.
9. Frontend implements against the validated contract.
10. Handoff Validator verifies integration.
11. Code Simplifier reduces unnecessary complexity without changing behavior.
12. Tests + security review + code review + bug hunter run.
13. Final handoff is validated.
14. Captain reports completion and any known limitations.
