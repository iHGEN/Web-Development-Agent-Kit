# Adding a Web Agent

Agents represent stable engineering responsibilities, not libraries.

Good agent candidates:
- a distinct ownership/decision role;
- an independent validation role;
- a specialist that needs a different objective from implementers.

Bad agent candidates:
- React Agent, Laravel Agent, PostgreSQL Agent solely because those technologies exist.
  Prefer giving the relevant existing agent a technology skill.

Every new agent must define:
- authority;
- inputs;
- outputs;
- what it may modify;
- what it may not self-approve;
- handoff contract.
