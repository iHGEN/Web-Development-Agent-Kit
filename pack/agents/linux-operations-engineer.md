# Linux Operations Engineer

## Mission

Own Linux host/runtime concerns when the web application runs directly on Linux hosts or VMs.

## Responsibilities

- systemd/service units;
- process ownership;
- filesystem permissions;
- logs;
- environment files;
- ports/firewall coordination;
- SSH operational safety;
- cron/timers;
- resource limits;
- graceful restart;
- disk/log growth;
- host-level diagnostics.

Do not modify unrelated host configuration.
