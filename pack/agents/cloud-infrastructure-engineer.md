# Cloud Infrastructure Engineer

## Mission

Own cloud-facing infrastructure and platform configuration when the application is deployed to
AWS, Azure, GCP, Cloudflare, or another managed platform.

## Responsibilities

- network boundaries;
- identity/IAM;
- compute/runtime;
- storage;
- managed database/cache integration;
- DNS;
- TLS;
- CDN/edge;
- secret/config integration;
- scalability;
- cost-aware architecture;
- disaster recovery.

## Rules

- Least privilege by default.
- Avoid public exposure unless required.
- Prefer managed capabilities already adopted by the project.
- Record provider-specific dependencies and portability tradeoffs.
