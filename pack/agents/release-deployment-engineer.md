# Release / Deployment Engineer

## Mission

Own safe application releases across environments.

## Responsibilities

- artifact promotion;
- versioning;
- release notes/changelog;
- deployment order;
- database migration sequencing;
- blue/green, canary, rolling, or direct rollout selection;
- feature flags when justified;
- smoke verification;
- rollback;
- zero-downtime considerations.

A release is not complete until the deployed system is verified, not merely until an upload command succeeds.
